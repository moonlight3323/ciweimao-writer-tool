# 稿费计算器

> 页面金额均为预估，稿费以实际发放为准。

[下载可直接导入的 v1.1.2 ZIP 插件包](https://github.com/moonlight3323/ciweimao-writer-tool/raw/refs/heads/main/plugins/income-calculator/刺猬猫稿费计算插件-v1.1.2.zip)

下载后在软件“插件中心 → 导入插件包”中选择该 ZIP 文件，无需解压。

默认规则：10,000 订阅、2,000 字按作者实得 400 元线性估算；D/C/B/A 全勤档分别为每千字 2/4/6/8 元；每日满 4,000 字才计全勤，每日最多按 20,000 字计算。

稿费统计日按刺猬猫时间刷新：每天 06:00 切换新的一天，00:00–05:59 的保存字数仍归入前一结算日。

稿费按成功保存的正文净新增字数计算，因此粘贴内容会计入稿费；粘贴内容仍不会计入“码字统计”。

多本书会分别记录已保存字数，并可为每本书设置不同的平均订阅数；统计页显示各书明细和所有现存作品合计。删除作品时，该作品贡献的稿费记录也会同步清除。当前档位为全局设置，D/C/B/A 固定按每千字 2/4/6/8 元计算。

## 单独导入测试

1. 彻底退出并重新打开作家助手。
2. 进入“插件中心”。如果列表中已经存在“稿费计算器”，先将它删除（同 ID 插件不能重复导入）。
3. 点击“导入插件包”，选择 `刺猬猫稿费计算插件-v1.1.2.zip`。
4. 确认插件已启用，左侧会出现“稿费统计”。
5. 在创作中心输入或粘贴正文并等待自动保存；码字面板下方会出现“本章预计稿费”，详情同时显示今日预计稿费。

## 文件说明

- `manifest.json`：插件信息、权限和页面/编辑器扩展声明。
- `page.html`：稿费统计与设置页面。
- `style.css`：页面样式。
- `main.js`：当日、7日、30日稿费计算与页面交互。
- `background.js`：编辑器右侧实时稿费指标。

插件设置和计算结果使用宿主提供的隔离存储及已保存码字统计，不会读取账号、Cookie 或密码。
