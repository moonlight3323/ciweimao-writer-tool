导出说明

导出的 TXT 采用 UTF-8 带 BOM 编码，Windows 记事本、WPS、Typora 都能直接打开不乱码； 换行用 CRLF，粘到别的编辑器里也是一段一行。

章节顺序按后台列表的顺序还原：如果后台是倒序排列（最新在前），工具会自动翻转成从第一章开始。 正文里的空行、分段会原样保留；「作者的话」如有会附在每章末尾。

如果某一章读不到正文（例如编辑器是前端渲染、或该章还是空白草稿），会在导出结果里单独列出来， 其余章节照常导出。

外观

主题

「粉白」是樱粉配色，按钮与卡片圆角更大、观感更柔和；深色适合夜间使用；选「跟随系统」会随 Windows 的浅色 / 深色设置自动切换。

深色配色

只影响深色模式。深黄黑保留原来的暖夜观感；深蓝黑整体偏冷蓝，主色从品牌金换成青蓝。切换时不用退出设置，直接生效。

评论审查

强度

标准：只标人身攻击、攻击性表达、广告、剧透、刷屏、无依据的严重指控；对作品的负面评价不处理。
严格：把「尴尬 / 暴死 / 扑街 / 离谱」这类负面评价也算进来。容易误伤——正常讨论里出现一个「离谱」就会被标红，建议只在集中清场时开。

设置保存后会立即重算当前评论，无需重新抓取。
