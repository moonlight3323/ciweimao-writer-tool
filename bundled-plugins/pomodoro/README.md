# 番茄钟

专注计时插件，从「健康小助手」里拆出来的独立功能。

## 能力

- **专注循环**：工作 / 休息交替，跑完设定轮次自动结束。
- **节奏预设**：把常用的「工作+休息」组合存下来，一键切换。
- **两种形态**：侧边栏（给码字台用）和悬浮球（常驻显示剩余时间与进度环）。
- **编辑区指标**：码字台右侧实时显示「第几轮 / 剩余时间」。
- **后台独立计时**：页面被切走也不影响，靠时间戳重算而非累加。

## 与「健康提醒」的分工

| 插件 | 管什么 |
|---|---|
| 番茄钟（本插件） | 专注计时、节奏预设 |
| 健康提醒（`health-helper`） | 喝水提醒、睡觉提醒 |

两者共用 storage 但各自独立开关：关掉番茄钟不影响喝水提醒，反之亦然。

**悬浮球只归番茄钟**：专注进度需要一直看得见，而喝水/睡觉本质是「到点提醒」，
不需要常驻一颗球。两个插件各挂一个球会叠在一起，所以健康提醒只保留侧边栏形态。

## 存储

`storage['state']`：

```json
{
  "mode": "ball",
  "work": 25,
  "rest": 5,
  "rounds": 4,
  "presets": [{ "name": "标准 25+5", "work": 25, "rest": 5, "rounds": 4 }],
  "timer": { "phase": "idle", "startedAt": 0, "round": 1, "pausedRemain": 0 },
  "ball": { "x": null, "y": null, "edge": "br" }
}
```

`timer.phase` 只有 `idle` / `work` / `rest` 三个值；`startedAt` 是毫秒时间戳，
剩余时间永远由 `phaseSeconds() - (now - startedAt)/1000` 现算，不做累加。
