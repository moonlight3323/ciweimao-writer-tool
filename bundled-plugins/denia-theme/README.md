# 达妮娅 · 虚无之泡（作家助手适配示例）

1.0.1 新增左上角侧栏图标更换。在“达妮娅主题 → 左上角侧栏图标”选择图片后，点击“保存并应用”。明暗形态默认使用各自的 Q 版图标，也可勾选“使用软件默认图标”。需要支持 themeBranding 能力的宿主。图标加载失败时保留软件默认图标，停用本主题也会恢复。

从作家助手“功能中心 → 导入扩展包”选择本 ZIP。需要已接入主题图片与组件样式接口（Plugin API 1.3.0）的宿主。

点击卡片的“布景之形”或“幻灭之形”应用主题；点击左侧“达妮娅主题”可打开调色板。支持替换背景图片、调整背景透明度与模糊、面板透明度、左右立绘、Q 版动态装饰、泡泡与装饰边框。设置按明暗形态分别保存在当前数据目录，点击“保存并应用”后生效。窄窗口会隐藏角色装饰。

在功能中心停用本插件，或在设置中恢复内置主题，即可撤下主题样式。主题不修改章节正文、字体偏好或账号数据。

示例根据用户本机已安装的 @dsh-external/dsh-client-ui-skin-denia 1.0.0 素材与视觉设计适配。主题图片、角色与视觉设计沿用原包署名及 CC BY-NC-SA 4.0 条款，见 LICENSE 和 NOTICE；本适配示例同样按该许可提供，非商业使用，衍生作品须保留完整署名链并以相同许可共享。
