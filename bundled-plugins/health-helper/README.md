# 健康提醒

喝水提醒 + 睡觉提醒。码字时的两个小闹钟。

## 能力

- **喝水提醒**：按设定的间隔倒计时，到点在页面内提示并自动重新计时；
  点「我喝了」可以手动提前开始下一轮。
- **睡觉提醒**：到设定时刻提示收工，每天只提示一次。
- **编辑区指标**：码字台右侧实时显示「下次喝水 42:15」。
- **设置面板**：喝水间隔、睡觉时间，两块分开放。

## 与「番茄钟」的分工

| 插件 | 管什么 |
|---|---|
| 健康提醒（本插件） | 喝水提醒、睡觉提醒 |
| 番茄钟（`pomodoro`） | 专注计时、节奏预设 |

两者共用 storage 但各自独立开关：关掉番茄钟不影响喝水提醒，反之亦然。

**本插件不再提供悬浮球**。悬浮球归番茄钟独占 —— 专注进度需要一直看得见，
而喝水/睡觉本质是"到点提醒"，不需要常驻一颗球；两个插件各挂一颗会叠在一起。

## 存储

`storage['state']`：

```json
{
  "waterMin": 45,
  "sleep": "23:30",
  "water": { "lastAt": 0 }
}
```

`water.lastAt` 是毫秒时间戳，剩余时间永远由
`waterMin*60 - (now - lastAt)/1000` 现算，不做累加 —— 所以页面被挂起再回来，
数字依然是对的。

## 版本历史

### 1.1.0

- **番茄钟拆成独立插件**（`pomodoro`）。本插件只保留喝水与睡觉提醒。
- 去掉悬浮球与形态切换（理由见上）。
- 界面从「一个长面板」改成「喝水 / 睡觉 两张卡片」，设置面板里两个功能各自成组。
- 兼容旧数据：旧版 `state.water` 如果是个数字（更早的字段名），会自动搬到 `waterMin`。

### 1.0.7

- 悬浮球改成奶油白底 + 琥珀色进度环（`.ring-bg` 的 `fill` 不能依赖 `var()`，
  SVG 默认填充是纯黑）。
- 设置面板遮罩从黑色半透明换成浅暖色 + 轻微模糊。
- 设置项拆成三块：番茄钟 / 喝水提醒 / 睡觉提醒。
