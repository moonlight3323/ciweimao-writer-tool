# 健康小助手

番茄钟 + 喝水提醒 + 睡觉提醒。码字时的一个小陪伴。

## 两种形态

- **悬浮球**：默认开启，可拖动的圆球，中间显示进度百分比；点开弹出倒计时面板。插件页面切走后，原生悬浮球仍会驻留在应用最上层。
- **侧边栏**：在设置里切换后，固定显示完整倒计时与进度条

在插件设置中可以切换侧边栏与悬浮球形态；插件默认使用悬浮球，不会在主侧栏增加单独的导航入口。

1.0.6 使用作家助手插件 API 1.1.0 的正式悬浮接口，随作家助手 1.0.5 内置安装。点击插件中心“打开”会打开悬浮球的设置；切换应用页面和打开其他插件不会再重建这个球。

## 悬浮球交互

- **拖动**：按住球体移动；离开插件页面后仍可拖动同一个原生悬浮球
- **放置**：松手停在当前位置，可以放在应用内的任意位置
- **弹窗方向**：根据当前位置自动选择；展开和收起时保持球的位置
- **开合**：点一下球展开，再点一下收起

## 计时逻辑

- 工作/休息时长、轮次都可调（1~180 分钟 / 1~60 分钟 / 1~12 轮）
- 可保存最多 8 套常用节奏，一键切换
- 工作结束自动进入休息，休息结束进入下一轮
- 全部轮次完成后自动停止

## 提醒

- **喝水**：独立计时，每 N 分钟提醒一次（默认 45 分钟），提醒后自动重置
- **睡觉**：到设定时间提醒一次（默认 23:30）
- 提醒形式为页面内浮动提示 + 球体/数字变红

**注意**：插件沙箱没有系统通知权限，所以不会弹窗、不会响铃。悬浮球由插件 iframe 自己绘制，宿主只负责让这个 iframe 在其他页面继续驻留。

## 数据

设置保存在插件自己的 storage 里，删除插件后设置仍会保留。
