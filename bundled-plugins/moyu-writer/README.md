# 摸鱼码字（moyu-writer）

内置功能。开启后，创作中心 → 码字台工具栏会出现「摸鱼码字」按钮。

## 它是什么

点按钮 → 软件窗口收起 → 屏幕上浮出一条几乎看不见的输入区。
在浮层里写的字按 120 毫秒的节奏回推到**当前章节**，走的是码字台原本的保存链路
（自动保存、字数、错别字扫描都照常）。

## 使用要点

- **字体跟随码字台**：浮层正文的字体族取自码字台「字体」设置（`WRITER_FONTS`，随 `open` 传给主进程，
  归一化后经 `overlay:init` 的 `font` 字段写进 `--font`）。字号和行距**不跟随**，
  仍由浮层自己的设置控制（默认 20px / 1.9，比码字台的 16px / 2.05 大一点，悬在别的窗口上才看得清）。
- 浮层顶部那条把手**整条都能拖**（36px 高、**不铺底色**，只有左端 6 点握把带一点淡粉方便认位置），
  光标是十字箭头。把手上的字色直接跟随「字色」设置，跟正文同色，描边开关也一起生效。
  拖动由 `overlay.js` 自己实现（按下报开始 → 主进程每 16ms 按系统光标挪窗口 → 松开停），
  **没有**用 `-webkit-app-region: drag`：那个属性由系统接管鼠标，页面收不到指针，
  光标也改不成十字箭头，透明无边框窗口上还会整个失灵。
- ⚙ 面板里点「快捷键」那一格，直接按下组合就能改：要带 Ctrl / Alt / Shift / Win 至少一个，
  主键可以是字母、数字或 F1–F24（单键不做全局热键，会吃掉整台机器的那个键）。
  设的组合被别的软件占用时自动退回内置链，面板标黄说明现在实际用的是哪个；↺ 恢复默认。
- **左键 + 右键同时按下** = 藏起来，浮层任意位置都行（包括把手）。

## 文件分工

这个文件夹只提供**功能中心的卡片与说明页**，真正的实现在宿主里：

| 位置 | 职责 |
|---|---|
| `src/main/moyu-writer.js` | 透明无边框窗口、置顶、位置尺寸记忆、全局快捷键、隐藏/恢复 |
| `src/main/moyu-config.js` | 设置归一化与快捷键降级链（纯函数，可单独测） |
| `src/renderer/overlay.html/.css/.js` | 浮层页面：编辑区、把手、字数、设置面板 |
| `src/preload/moyu-preload.js` | 浮层窗口的专用桥 |
| `src/renderer/app.js`（摸鱼码字段） | 按钮显隐、把浮层文本覆盖回正文 |

清单里的 `contributes.editorButton` 是宿主画工具栏入口的依据；
宿主目前只给内置的摸鱼码字接了具体动作，别的插件声明了不会长按钮。

## 改什么会坏

- 把 `contributes.editorButton` 删掉 → 码字台按钮不再出现（开关仍可开，但没入口）。
- 把 `permissions` 里的 `editor.read` / `editor.write` 删掉 → 功能中心卡片上的权限说明会少两条。
  权限目前只用于展示与插件 API 放行，宿主自己的功能不依此校验。
- 目录名必须等于 `manifest.id`，打包时 `installBundled` 按目录名对账。
