# 刺猬猫作家助手 v1.0.0 更新说明

> 这是第一个正式版。功能与 v0.14.1 相比有较大扩充，主要围绕「码字」这一核心环节重做了一遍。

## 专注模式

- 创作中心工具栏新增「专注模式」：隐藏左侧导航、顶栏与右栏统计，只留章节目录与正文，窗口同时最大化。
- 再点一次退出，界面与窗口恢复原状；如果进入前窗口本来就是最大化，退出后保持最大化，不会被缩小。
- 专注模式下码字统计改为贴在窗口右侧中间的悬浮卡片，点工具栏的「码字统计」随时展开或收起。
- 专注模式下页面宽度自动给到 1100，需要更宽可以在显示设置里继续加。

## 码字显示设置

- 工具栏新增「显示设置」：字体、字号、行距、页面宽度都可调，改动即时生效并记住。
- 字号、行距、页面宽度改用加减号微调，一次一格，比拖动滑块好对准。
- 点面板外的任意位置或按 Esc 自动收起。
- 页面宽度上限放宽到 1600，配合专注模式使用。
- 新增「恢复默认」一键还原。

## 深色模式

- 码字台工具栏新增深色一键开关，点一下切深色，再点退回浅色。
- 深色提供两套配色，可随时切换：
  - **深黄黑**：原有的暖夜观感，主色为品牌金。
  - **深蓝黑**：冷蓝底 + 青蓝主色，适合夜间长时间码字。
- 设置 → 外观里也能选，切换时不用退出设置。
- 敏感词悬浮窗、插件页面、折线图都会跟着一起变。
- 重启软件时不会先闪一下另一套配色。

## 正文实时敏感词检测

- 码字时自动比对本地敏感词库，命中的词在正文中高亮标出，右栏同时列出行与上下文。
- 每个命中词提供四个处理选项：加间隔号、换近义词、删掉、无视。
- 选「无视」后该词立刻恢复正常，本章不再提示，换章自动恢复检测。
- 单字词不参与高亮，避免「的」「了」这类误报把整章刷红。
- 敏感词库支持手动添加：设置 → 敏感词库，逗号、顿号、空格、换行都算分隔符，加完码字台立刻换表，不用重启。

## 码字与目录

- 回车时自动补两个全角空格的段首缩进，与「一键排版」的结果一致；Shift+回车保留纯换行。
- 一行写满自动折行的部分仍然顶格，不会凭空多出缩进。
- 章节目录统一按章节号正序排列，最新的在最下面；不再出现「有的正序、有的倒序」。
- 打开作品时默认停留在最新一章，目录自动滚到对应位置。
- 作品库新增「读取全部章节」：一次把还在空壳状态的作品正文从后台读下来，已有正文的书不会被覆盖。
- 作品库的导入、读取、同步三个按钮旁加了问号说明，鼠标移上去能看到各自做什么。

## 作者信箱

- 「一键清除小红点」新增停止按钮：清理过程中随时可以停，已经点过的不会恢复，剩下的再点一次就能接着清。
- 停止会同时作用于页内逐行点击与分页循环，不会等当前页把剩下的条目全部点完。

## 首次使用引导

- 第一次打开软件时说明要做什么，并提供「打开作者后台」直达按钮。
- 第一次登录成功后提示去抓取评论，并提供「去抓取与同步」直达按钮。
- 「抓取与同步」顶部新增三步引导：读取作品列表 → 开始抓取 → 到数据看板刷新数据，当前该做哪步会高亮。
- 抓取完成后的提示里写清哪部分数据会自动更新、哪部分需要手动刷新，并给出跳转按钮。
- 登录页的密码本工具条首次出现时展开用法说明，之后可通过「怎么用」再看。

## 关闭行为与托盘

- 软件常驻系统托盘，左键点击托盘图标显示主界面，右键菜单可退出。
- 第一次点关闭按钮时询问「最小化到托盘」还是「直接退出」，选择后记住，之后不再打扰。
- 设置 → 窗口可随时更改这个偏好。
- 询问框改用软件自己的卡片样式，不再是系统灰底对话框。

## 主题与外观

- 敏感词悬浮窗、插件页面改为跟随当前主题，粉白主题下不再一半粉一半黄。
- 粉白主题换用粉色刺猬品牌图标，切换主题时自动跟着换。
- 粉白主题的主按钮与稿费金额配色调淡，不再显得发暗。
- 分段控件（风险筛选、审查类型等）由竖椭圆改为小圆角矩形。
- 「敏感词侧栏」按钮加深配色，更容易看到。
- 后台工具栏的前进 / 后退按钮改为「← 创作中心」：一次点击回到本地界面，后台页面不销毁，再进去还是刚才那一页。

## 交互细节

- 界面文字不再能通过拖动被框选，输入框、正文、评论内容、路径等确实需要复制的区域仍可正常选择。
- 抓取、同步等操作的进行状态与结果都写在页面上方，不再只留控制台。

## 修复

- 修掉「关掉敏感词侧栏后再发布，侧栏点了没反应」：改为每次推送前确认窗口真实可见性，而不是依赖本地标记。
- 修掉右下角「侧栏已收起」提示挂到其他界面的问题：改为 8 秒自动消失，离开码字台立刻收掉。
- 修掉「再点打开作者后台会跳回首页、把正在填的表单冲掉」：改为复用已有的后台页面，不重新加载。
- 修掉关闭行为选「直接退出」后窗口关了、托盘图标还在、点一下又能打开的问题。
- 修掉升级时反复弹出命令行黑窗口的问题。
- 修掉更新下载没有进度的问题：改为边下载边写入，进度条与已下载大小实时变化。
- 修掉每次更新在临时目录留下约 3 MB 文件的问题：启动时自动清理旧版本残留，正在等待重启的那一份会保留。
- 修掉「敏感词侧栏」因主题值被折成浅色而永远不跟随粉白主题的问题。
