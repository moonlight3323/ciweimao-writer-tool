# 自己做一个美化包

这份说明是给**用软件的人**看的，不需要会编程。你只要准备好图片、把要求讲给自己的 AI 听，剩下的交给它生成文件，你负责双击导入。

如果你是想从头写插件的开发者，看另一份《插件开发说明.md》；这份只讲美化包（扩展主题）这一件事。

---

## 0. 一分钟看懂

美化包就是一个 ZIP 文件，里面装三样东西：

| 内容 | 作用 | 谁来准备 |
| --- | --- | --- |
| `manifest.json` | 说明书：叫什么名字、用哪套明暗底、各个位置什么颜色、图片叫什么 | 让你的 AI 生成 |
| `assets/` 里的图片 | 背景图、立绘、小装饰、侧栏图标 | 你准备（或让 AI 生图） |
| `README.md`、`LICENSE` | 可选，作者与授权说明 | 让你的 AI 生成 |

导入后到 **设置 → 外观 → 扩展主题** 选一下就能用（软件自带的那套会在第一次打开时自动用上）。整个过程不用改软件本体，随时能换回内置主题。

---

## 1. 美化包会改到哪些地方

先知道自己的图会落在哪儿，准备素材时才有数。

| 位置 | 说明 | 靠什么控制 |
| --- | --- | --- |
| 整体背景 | 铺在窗口最底层的一张图 | `background` |
| 侧栏 / 顶栏 / 卡片 / 对话框 | 半透明玻璃、描边、圆角、阴影 | `styles` |
| 按钮 / 输入框 / 选中项 | 主色按钮、普通按钮、输入框、导航选中态 | `styles` |
| 码字台 | 纸面、目录、右侧统计、工具栏 | `styles`（`writerPaper` 等） |
| 左下角 / 右下角立绘 | 站在窗口边上的角色图（最多 6 个） | `decorations` |
| 侧栏图标 | 左上角那个小 logo | `branding.icon` |
| 气泡 / 星星 / 收边 | 可选的小动态效果 | `effects` |
| 全部文字与主色 | 文字深浅、品牌色、图表配色 | `variables` |

## 2. 你需要准备哪些图片

### 2.1 图片清单

**关键前提：明暗各一套。** 美化包生效期间，软件里的「深色 / 浅色」切换会被锁定（这是故意的，见第 6 节）。所以一个包必须自带浅色和深色两套图，用户靠主题选择切换，而不是靠那个按钮。

| 文件名（建议） | 用途 | 建议尺寸 | 格式 | 透明底 | 必须 |
| --- | --- | --- | --- | --- | --- |
| `palace-light.webp` | 浅色模式的整窗背景 | 1920×1080 或更大，横图 | WebP / PNG / JPEG | 不需要 | 建议 |
| `palace-dark.webp` | 深色模式的整窗背景 | 同上 | 同上 | 不需要 | 建议 |
| `left-light.webp` | 左下角立绘（浅色） | 宽 800～1400，竖图，**底部要裁齐** | WebP / PNG | **需要** | 可选 |
| `left-dark.webp` | 左下角立绘（深色） | 同上 | 同上 | **需要** | 可选 |
| `right-light.webp` | 右下角立绘（浅色） | 同上 | 同上 | **需要** | 可选 |
| `right-dark.webp` | 右下角立绘（深色） | 同上 | 同上 | **需要** | 可选 |
| `chibi-light.gif` | 侧栏底部的小装饰，可动 | 正方形 256×256 起 | GIF / WebP / PNG | **需要** | 可选 |
| `chibi-dark.gif` | 同上，深色版 | 同上 | 同上 | **需要** | 可选 |
| `icon.png` | 左上角侧栏图标 | 256×256（显示时是 34×34） | PNG | **需要** | 可选 |

只要背景 + 配色，也能做出一个完整能用的包；立绘和图标属于加分项，没有不影响使用。

### 2.2 硬性规矩（不符合会被直接拒绝）

| 规矩 | 具体要求 |
| --- | --- |
| 位置 | 所有图片必须放在包内的 `assets/` 目录下 |
| 文件名 | 只能用**英文、数字、横线、下划线**，例如 `left-dark.webp`。中文名、空格、括号都不行 |
| 格式 | PNG、JPEG（`.jpg`/`.jpeg`）、WebP、GIF |
| 单张大小 | 不超过 **8MB** |
| 整个包 | ZIP 本身和解压后总量都不超过 **32MB** |
| 版权 | 用你自己的图、约稿图或有授权的图。拿别人的作品做成包分发会有麻烦 |

现成的图太大怎么办：用任何看图/压缩工具把长边缩到 1920 左右、导出 WebP（质量 80 左右），通常能从 5MB 降到 300KB 以内，画质在软件里看不出差别。

## 3. 颜色要定哪些

不用全填。**最少给主色 + 底色 + 文字色这几项**，没填的会沿用基础上（`light` / `pink` / `dark`）。

| 分组 | 变量 | 说明 |
| --- | --- | --- |
| 底色 | `--bg` | 窗口最底层颜色（有背景图时也是它透出来的底） |
| 表面 | `--surface` `--surface-2` `--surface-3` `--surface-4` | 卡片、侧栏、悬浮层，从浅到深四档 |
| 描边 | `--border` `--border-strong` | 细描边、强调描边 |
| 文字 | `--text` `--text-2` `--text-3` | 正文、次要文字、灰色提示 |
| 主色 | `--accent` `--accent-hover` `--accent-weak` `--accent-ink` `--accent-line` | 品牌色、悬停、浅底、深字、描边 |
| 状态 | `--ok-bg` `--ok-ink` `--warn-bg` `--warn-ink` `--danger-bg` `--danger-ink` `--danger-line` | 成功 / 警告 / 危险 |
| 涨跌 | `--up` `--down` | **涨用红、跌用绿**（国内习惯） |
| 标签 | `--chip-bg` `--chip-ink` `--hl-bg` `--hl-ink` | 小标签、高亮 |
| 控件 | `--track` `--seg-active` `--step-bg` | 分段控件底、选中块、步骤条 |
| 图表 | `--chart-line` `--chart-grid` `--chart-ink` `--chart-dot` | 折线、网格、刻度、数据点 |
| 属性色 | `--props-c1` `--props-c2` `--props-c3` `--props-c4` | 数据对比的四色 |
| 其他 | `--scroll` `--scroll-hover` `--chevron` | 滚动条、悬停、下拉箭头 |
| 圆角 | `--radius` | 只能写 `0px`～`24px`，例如 `14px` |

颜色格式：`#RGB`、`#RRGGBB`，或带透明度的 `#RRGGBBAA`（比如 `#fffbffb8` 是八分透明）。不要写 `red`、`rgba(...)`、`var(...)`。

## 4. 怎么讲给自己的 AI（重点）

不用背字段。把下面这段**整段复制**给你常用的 AI（豆包、DeepSeek、ChatGPT、Claude 都行），把方括号里的内容换成你自己的。

### 4.1 第一段：让它生成美化包

```text
你是「刺猬猫作家助手」美化包（扩展主题）的制作助手。请帮我生成一个可以直接导入的美化包。

【我要的风格】
主题名：[夜樱 / 深海 / 我推的角色名 ……]
风格描述：[例如：深紫夜色、樱花点缀、玻璃质感卡片、圆角偏大]
主色：[#9b6bd8]  浅色底：[#f4eff9]  深色底：[#171326]
文字要清楚，浅色主题用深色字、深色主题用浅色字。

【我会提供的图片】（都放在 assets/ 目录，文件名已经定好，不要改）
palace-light.webp / palace-dark.webp   整窗背景
left-light.webp  / left-dark.webp      左下角立绘（透明底）
right-light.webp / right-dark.webp     右下角立绘（透明底）
chibi-light.gif  / chibi-dark.gif      侧栏底部小装饰（透明底）
icon.png                               侧栏图标（透明底，256×256）

【请输出这些文件】
1. manifest.json
2. README.md（写明主题名、作者、用了哪几张图、怎么导入）
3. LICENSE（写：仅限个人使用，不得商用分发）

【manifest.json 必须严格遵守的规则】
- 顶层：id（2～64 位，只能小写字母、数字、横线、下划线，以字母或数字开头，例如 my-night-sakura）、
  name、version（如 "1.0.0"）、author、description、permissions: ["ui.theme"]。
- contributes.themes 是一个数组，**必须给两套**：一套 base 为 "light"，一套 base 为 "dark"，
  id 分别如 my-theme-light / my-theme-dark，各带 name（中文名）。
- 每套主题的 variables 只能用下面这些键，值是 "#RRGGBB" 或 "#RRGGBBAA"，--radius 只能是 0px～24px：
  --bg --surface --surface-2 --surface-3 --surface-4 --border --border-strong
  --text --text-2 --text-3 --accent --accent-hover --accent-weak --accent-ink --accent-line
  --ok-bg --ok-ink --warn-bg --warn-ink --up --down --danger-bg --danger-ink --danger-line
  --chip-bg --chip-ink --hl-bg --hl-ink --track --seg-active --step-bg
  --chart-line --chart-grid --chart-ink --chart-dot --props-c1 --props-c2 --props-c3 --props-c4
  --scroll --scroll-hover --chevron --radius
  绝对不要出现上面没列出的键（例如 --font、--shadow），会被导入直接拒绝。
- background 只能有：image（"assets/xxx.webp"）、opacity（0～1）、blur（0～24）、
  fit（"cover" 或 "contain"）、position（"center"/"top"/"bottom"/"left"/"right"）。
- styles 只能使用这些插槽：sidebar topbar panel button primaryButton navItem navActive
  input writerWorkspace writerPaper writerDirectory writerStats toolbar dialog title
  每个插槽只能写：background color borderColor（这三个是 #颜色）、borderWidth 0～6、
  borderStyle（solid/dashed/dotted/double）、borderRadius 0～48、backdropBlur 0～24、
  fontWeight 400～800、paddingX 0～32、paddingY 0～24、
  shadow {x -24~24, y -24~48, blur 0~80, spread -20~20, color #色}、
  gradient {from #色, to #色, angle 0~360}。
  浅色主题的卡片用半透明浅色（如 #ffffffb8）+ backdropBlur，深色主题用半透明深色。
- decorations 最多 6 个，每个：id（小写字母数字横线下划线）、image（"assets/xxx.webp"）、
  anchor（bottom-left / bottom-right / top-left / top-right / sidebar-bottom）、
  layer（background 或 foreground）、width（32～640，单位 px）、
  height（10～85，表示最大高度占窗口的百分比，不是像素）、
  opacity（0～1）、offsetX（-200～400）、offsetY（-200～400）。
  立绘一般设 anchor 为 bottom-left / bottom-right、layer 为 background、width 220～300、height 60～70。
- branding 里只有 icon，值写 "assets/icon.png"。
- effects 只能写：bubbles（true/false）、bubbleCount（4～30）、bubbleSpeed（0.3～2）、
  trim（true/false）、stars（true/false）。不需要就不要写这一段。
- 图片路径一律写成 "assets/文件名"，不要写绝对路径、不要写 data:base64、不要用中文名。

【最后帮我自查一遍】
逐个检查：所有键名在允许列表内、所有颜色都是 # 开头、所有图片路径都在 assets/ 下且文件名只用
英文数字横线下划线、浅色主题文字是深色、深色主题文字是浅色、两个主题 id 不重复。
发现问题直接改，然后把最终文件内容给我。
```

如果 AI 只能输出文字，就让它**依次给出每个文件的完整内容**，你自己在电脑上建文件夹粘进去；如果它能生成 ZIP，就让它直接给 ZIP。

### 4.2 第二段：让 AI 顺便帮你写配色

懒得起草颜色时，先单独要一套配色，再塞进上面的模板：

```text
请按「深紫夜色 + 樱花点缀」帮我定一套界面配色，输出 JSON，只包含这些键：
--bg --surface --surface-2 --surface-3 --accent --accent-ink --text --text-2 --text-3
--border --up --down --radius
要求：浅色版保证正文对比度够（白底深字），深色版不要纯黑、不要把文字压在低对比灰上；
--radius 给一个 0px～24px 的值。颜色只用 #RRGGBB 或 #RRGGBBAA。
```

### 4.3 第三段：导入失败时怎么问

把软件给的报错原文贴给 AI，加上这句：

```text
这是「刺猬猫作家助手」导入美化包时的报错原文：「……」
它来自 manifest.json 的字段校验（只允许白名单字段、颜色必须是 # 开头、图片必须在 assets/ 下）。
请指出是哪个字段错了，并给出改好的完整 manifest.json。
```

## 5. 打包与导入

1. 在电脑上建一个文件夹，例如 `my-theme`，里面放：
   ```
   my-theme/
     manifest.json
     README.md
     LICENSE
     assets/
       palace-light.webp
       palace-dark.webp
       left-light.webp
       ...
   ```
2. 全选这些**内容**压成 ZIP。注意：打开 ZIP 应该直接看到 `manifest.json`，**不要**多套一层 `my-theme/` 文件夹，否则导入会失败。
3. 软件里进 **功能中心**，导入这个 ZIP → 启用。
4. **设置 → 外观 → 扩展主题**，下拉里选你的主题，浅色 / 深色两套都会出现。
5. 想换回原来的样子：下拉里选「使用内置主题」，或点「恢复内置主题」。

不是自己做的包也走同一条路：拿到别人的 ZIP，功能中心导入即可。装别人做的包前确认来源可信，美化包不会碰你的作品和账号数据，但来源不明的文件一律别装。

**想照着现成的改**：软件自带一套「达妮娅 · 虚无之泡」主题包（功能中心里已装好并启用，第一次打开软件就会自动用上浅色或深色那套；之后在设置 → 外观 → 扩展主题里改选）。它的完整结构就在软件的 `resources\app\bundled-plugins\denia-theme\` 目录里：`manifest.json` 里两套主题、`assets/` 里八张图、`page.html` + `main.js` 是它自己的调色板页面。想做自己的，最快的方式是把这个目录整个复制出来，换掉图片、改个 `id` 和名字，再压成 ZIP 导入——比从空白开始省一半功夫。注意它的图片与配色沿用上游 CC BY-NC-SA 4.0（见包内 LICENSE 与 NOTICE），自己二次创作时保留署名、别用于商业用途。

## 6. 用了美化包之后，深浅切换为什么点不动

这是**设计如此**，不是坏了。

美化包自带一整套明暗配色（就是你清单里那两套），如果这时再点「深色 / 浅色」按钮，软件只能二选一：要么按按钮切走、把美化包整体撤掉，要么按美化包显示、让按钮失效。上一版是前者，表现出来就是「点一下切换，美化包直接没了」。

现在的处理是后者：

| 状态 | 侧栏深色按钮 | 设置里的主题档位 | 深色配色（深黄黑 / 深蓝黑） | 创作中心的深色按钮 |
| --- | --- | --- | --- | --- |
| 用内置主题 | 可点 | 可点 | 可点 | 可点 |
| 用美化包 | **灰掉、点不动** | **灰掉** | **灰掉** | **灰掉** |

鼠标停在灰掉的按钮上会提示「已启用扩展主题「XX」，深浅切换已锁定；在设置 → 外观里选「使用内置主题」后恢复」。

**要恢复**：设置 → 外观 → 扩展主题 → 选「使用内置主题」（或点「恢复内置主题」）。锁定立刻解除，深浅切换和深色配色都回到原来的用法，你原来选的内置主题也还在。

想白天用浅色版、晚上用深色版？在下拉里切换两套主题就行，那是美化包自己的明暗，不影响锁定状态。

**在功能中心把扩展关掉再打开**：关掉期间界面会临时回到内置配色，但你选的那套会记着；重新打开这个扩展，主题自动恢复，不用再去设置里重挑一次（关掉软件再打开也一样记得）。如果确实不想用了，把扩展删除才会一起清掉这个记录。

## 7. 常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 导入时提示「图片仅支持 assets 下的 PNG、JPEG、WebP、GIF」 | 文件名带中文/空格，或路径不是 `assets/xxx` | 改文件名只用英文数字横线下划线，放到 `assets/` 里 |
| 提示「不支持的主题变量 --xxx」 | 写了白名单外的变量 | 删掉那一行，或换成最近似的白名单变量 |
| 提示「主题变量格式无效」 | 颜色写成了 `red` / `rgba()` / 少了 `#` | 统一改成 `#RRGGBB` 或 `#RRGGBBAA` |
| 导入成功但列表里没有 | 插件 ZIP 多套了一层文件夹，或没启用 | 重新压成「打开就是 manifest.json」；到功能中心确认已启用 |
| 背景图不显示 | 路径写错、图片超过 8MB | 核对 `"assets/文件名"` 大小写完全一致；压缩图片 |
| 背景太抢眼，看不清字 | `opacity` 太高 | 把 `background.opacity` 调到 0.25～0.4，或在 `styles` 里给卡片加 `backdropBlur` |
| 立绘太大 / 挡住按钮 | `width` 或 `height` 给大了 | `width` 调 220～300（px），`height` 调 55～70（百分比） |
| 立绘位置偏了 | `offsetX` / `offsetY` 不合适 | 小幅调 `offsetX`（正数往外、负数往里） |
| 深色主题字看不清 | 文字色和底色对比不够 | 深色主题的 `--text` 用接近白的色，`--surface` 别用纯黑 |
| 换了主题但没变化 | 选的是同一套，或插件被停用 | 下拉里重新选一次；功能中心确认插件在用 |
| 打开软件就是达妮娅主题，想回原来的配色 | 自带主题包首次启动会自动套用（装了、开着就该看到效果） | 设置 → 外观 → 扩展主题 → 选「使用内置主题」，之后重启也不会再自动套回 |
| 关掉扩展再打开，主题没了 | 旧版本会这样，停用即清除选择 | 1.1.3 起停用只暂存选择，重新启用会自动恢复；若仍不恢复，确认扩展是「启用」且主题还在包里 |

## 8. 附：最小可用的 manifest.json

只要背景 + 配色也能跑。这是骨架，把颜色和图片名换成你自己的：

```json
{
  "id": "my-night-theme",
  "name": "我的夜色",
  "version": "1.0.0",
  "author": "你的名字",
  "description": "深紫夜色 + 樱花点缀",
  "permissions": ["ui.theme"],
  "contributes": {
    "themes": [
      {
        "id": "my-night-light",
        "name": "夜色·浅",
        "base": "light",
        "variables": {
          "--bg": "#f6f1fb",
          "--surface": "#ffffffe0",
          "--surface-2": "#f3ecfa",
          "--text": "#3d3050",
          "--text-2": "#6f6083",
          "--text-3": "#9a8bab",
          "--accent": "#9b6bd8",
          "--accent-ink": "#5a3a78",
          "--accent-line": "#b08ccb",
          "--border": "#ddcfe9",
          "--radius": "14px"
        },
        "background": { "image": "assets/palace-light.webp", "opacity": 0.3, "blur": 0, "fit": "cover", "position": "center" },
        "styles": {
          "sidebar": { "background": "#ffffffb0", "backdropBlur": 10, "borderColor": "#ddcfe9" },
          "panel": { "background": "#ffffffb8", "borderColor": "#ddcfe9", "borderRadius": 18, "backdropBlur": 12 },
```
