# 刺猬猫作家助手 v1.0.3 更新说明

## 作者库章节同步

- 登录成功后自动检查已绑定作品的后台章节目录。
- “同步作者库”会增量读取本地缺少的新章节，不覆盖本地已有正文。
- 应用外新建且已有章节的作品会显示为“待同步”，点击后可读取正文。
- 正在编辑且尚未保存的作品会暂缓同步，避免覆盖本地修改。

## 同章冲突与发布状态

- 按分卷和章节号识别本地章节与后台章节的同章冲突，无章节号时按标题识别。
- 冲突内容不会互相覆盖，两份正文都会保留。
- 目录和编辑器标题区域会显示“已发布”“未发布”及“同章冲突”状态。
- 从网页同步到本地的章节标记为“已发布”；本地新建、导入和缓存章节标记为“未发布”。

## 错别字识别

- 创作中心增加本地离线错别字检测，支持常见错写、成语错写、重复字和重复标点识别。
- 正文中以提示色标记疑似错别字，右侧面板显示候选、上下文和修改建议。
- 支持替换当前错别字、忽略本章提示和永久忽略词语。
- 错别字面板与码字统计区域在系统最大化和专注模式下自适应布局。
