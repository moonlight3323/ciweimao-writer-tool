# 刺猬猫作家助手 v1.0.7 更新说明

本版以「数据看板」和「设置」为重点：新增数据管理、侧边栏调整、番茄钟独立成内置功能，数据看板改成概览与单本详情两级，并修掉了榜单刷新卡死、登录引导误弹等几个影响使用的问题。

## 数据管理：清除与恢复

- 设置新增「数据管理」，可以把软件恢复到刚装好的状态，测完整流程时不用再手动删文件夹。
- 「清除所有数据」会清掉作品库与章节草稿、敏感词库、功能设置、统计快照、界面偏好、密码本与登录态，然后自动重启。
- 清除前会自动备份一份，备份放在 `%APPDATA%\刺猬猫作家助手-数据备份\`，与软件数据目录分开存放，清数据时不会被一起删掉。
- 「立即备份一份」可以随时手动留档；备份按时间倒序排列，标明是清除前、恢复前还是手动备份。
- 「恢复数据」从本机备份还原，范围是备份当时的全部内容。恢复前会先把当前状态再备份一次，选错了还能退回来。
- 登录态不在备份里：恢复后需要重新登录作者后台。
- 浏览器缓存这类文件在软件运行时删不掉，改用 Electron 自己的清空接口处理，清完立即落盘，不会留下半清状态；清理失败的个别文件会如实列出来，不再一句报错就中断。

## 侧边栏调整

- 设置 → 侧边栏新增「调整侧边栏」，点开后左边每一项右侧出现上移、下移和移除按钮，此时才会显示这些按钮。
- 调整会立刻在左侧预览；点「保存排列」才真正生效，并结束调整、收起这些按钮。
- 不保存就离开设置页，改动自动还原。
- 「概览」「数据看板」「抓取与同步」「功能中心」「设置」这五项固定保留：不显示移除按钮，但上下顺序照样能调。
- 新增「退出调整」：进入调整态后即使什么都没改，也能一键退出，不会出现「三个按钮一个都点不了」的死路。
- 「恢复初始」立刻回到默认排列并结束调整，之后仍可继续调整。

## 番茄钟与健康提醒

- 番茄钟从「健康小助手」里独立出来，成为功能中心里单独一项，可单独开关。
- 番茄钟功能保持不变：工作 / 休息循环、常用节奏预设、悬浮球实时显示剩余时间。
- 原来的健康小助手更名为「健康提醒」，只保留喝水提醒和睡觉提醒，界面与主体风格统一。
- 两个功能互不依赖：关掉番茄钟不影响喝水提醒，反过来也一样。
- 悬浮球跟着各自功能走，不开启就不占桌面。

## 数据看板

- 概览是一本一张卡、六项指标（总字数 / 收藏 / 新增订阅 / 章节均订 / 总订阅 / 日均追订）对齐排列，点卡片任意位置进入这本的详情。
- 单本详情把完整指标、其他指标（本月更新、更新天数、满勤、断更、订阅最高单章）、每日趋势与道具获得合并在同一页，点「← 返回全部作品」回到概览。
- 顶部汇总卡仍是四项合计，切到单本时按这本书重算。
- 点亮星标的书排在概览第一张，并带实心星和一层强调底色，一眼能找到。
- 卡片支持键盘：Tab 选中后按 Enter 或空格进入详情。

## 道具获得

- 数据看板下方新增「道具获得」，读数取自作者后台「统计中心 → 道具获得」。
- 展示总推荐票、总月票、总打赏、总刀片四项，并显示与前一日相比的差值。
- 支持切换作品查看，默认跟随创作中心里点亮星标的那一本；进了某本详情就自动跟着这本书走。
- 新增道具获得趋势图，可切换近 7 日、近 30 日、按月；四条线共用一套刻度，未抓取的日子留空而不是画成 0。
- 平台有明细时按原表格列出；平台显示「暂无任何数据」时也会如实说明。

## 书籍优先级

- 创作中心每本书封面右上角新增星标，点亮即设为优先级，不再和「已入库 / 已上架」的来源标签叠在一起。
- 点亮的书排在创作中心「优先级作品」栏最前面；数据看板里同样排第一，并带实心星。
- 同时点亮多本时，最近点亮的那本优先；在数据看板手动选过查看范围后，不再被星标改回来。
- 优先级排序有兜底：无论界面脚本加载顺序如何，标星那本都会排到第一位，不会出现「星标亮着却排在后面」。

## 功能中心

- 「插件中心」更名为「功能中心」，导航与页面文案一并更新。
- 内置功能与自行导入的扩展分组显示，内置功能标注「内置」。
- 内置功能可以随时开关，但不能删除——删除后没有重新安装的入口。
- 功能列表为空时会自动补装内置功能；仍然补不出来时提示「重新加载」或重启，不会留一个空页面。

## 密码本

- 保存的账号可以记录作者名，登录成功后会自动读取当前作者名并绑定。
- 账号下拉按作者名显示，形如「笔名 · 账号」，多账号时更容易分辨。
- 新增「管理」面板，可多选批量删除，也可逐条手动标注或修改作者名。

## 版本检测与数据继承

- 手动下载完整包覆盖安装后，会询问是否继续使用旧版本数据。
- 软件自己提示并安装的更新直接跳过询问，不打断使用。
- 选择「不继承」会先自动备份，再清空数据从头开始。

## 问题修复

- 平台榜单点「刷新」后卡在「抓取中…」：给抓取加了超时与重试，界面侧也有兜底时限，无论主进程卡在哪一步，按钮都会自己恢复。
- 新用户点「打开作者后台」就被当成已登录、直接弹出抓取引导：改为必须真的从登录页跳回作者主页才算登录成功。
- 提示条一直消不掉：普通提示 6 秒自动收起，错误提示 12 秒，只有明确要求常驻时才会留着；自动同步的进度不再刷到界面上，不会看起来像卡死。
- 更新窗口与新增的确认框会被内嵌的作者后台 / 喵语数据页面挡住：打开前先把内嵌页面摘下，关闭后原样挂回，页面与填了一半的表单都保留。
- 深色模式、关闭按钮、窗口分段等控件集体失效：修掉了预加载脚本里同名接口互相覆盖的问题，并补了接口契约测试，避免同类问题再次静默发生。
- 健康小助手的悬浮球与面板出现过纯黑底：改为跟随主题色，并在配色变量失效时回落到明确的浅色，不再是 SVG 默认黑。

## 获取与更新

已有用户可通过软件内的更新提示升级。新用户请下载本次 Release 的 `ciweimao-writer-tool-v1.0.7-windows-x64.zip` 完整免安装包，解压后启动。

`ciweimao-writer-tool-v1.0.7-app.zip` 为软件内置更新器使用的应用更新包，不是独立运行的完整程序。

从 1.0.6 升级会保留原有作品、草稿、敏感词库与密码本；升级前建议在「设置 → 数据管理」里点一次「立即备份一份」。
