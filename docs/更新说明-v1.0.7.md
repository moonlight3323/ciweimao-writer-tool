# 刺猬猫作家助手 v1.0.7 更新说明

## 数据管理：清除与恢复

- 设置新增「数据管理」，可以把软件恢复到刚装好的状态，测完整流程时不用再手动删文件夹。
- 「清除所有数据」会清掉作品库与章节草稿、敏感词库、功能设置、统计快照、界面偏好、密码本与登录态，然后自动重启。
- 清除前会自动备份一份，备份放在 `%APPDATA%\刺猬猫作家助手-数据备份\`，与软件数据目录分开存放，清数据时不会被一起删掉。
- 「立即备份一份」可以随时手动留档；备份按时间倒序排列，标明是清除前、恢复前还是手动备份。
- 「恢复数据」从本机备份还原，范围是备份当时的全部内容。恢复前会先把当前状态再备份一次，选错了还能退回来。
- 登录态不在备份里：恢复后需要重新登录作者后台。

## 侧边栏调整

- 设置 → 侧边栏新增「调整侧边栏」，点开后左边每一项右侧出现上移、下移和移除按钮。
- 调整会立刻在左侧预览；点「保存排列」才真正生效，并结束调整、收起这些按钮。
- 不保存就离开设置页，改动自动还原。
- 「恢复初始」立刻回到默认排列，之后仍可继续调整。
- 「设置」这一项不能移除——它是恢复侧边栏的唯一入口。

## 道具获得

- 数据看板下方新增「道具获得」，读数取自作者后台「统计中心 → 道具获得」。
- 展示总推荐票、总月票、总打赏、总刀片四项，并显示与前一日相比的差值。
- 支持切换作品查看，默认跟随创作中心里点亮星标的那一本。
- 新增道具获得趋势图，可切换近 7 日、近 30 日、按月；四条线共用一套刻度，未抓取的日子留空而不是画成 0。
- 平台有明细时按原表格列出；平台显示「暂无任何数据」时也会如实说明。

## 版本检测与数据继承

- 手动下载完整包覆盖安装后，会询问是否继续使用旧版本数据。
- 软件自己提示并安装的更新直接跳过询问，不打断使用。
- 选择「不继承」会先自动备份，再清空数据从头开始。

## 功能中心

- 「插件中心」更名为「功能中心」，导航与页面文案一并更新。
- 内置功能与自行导入的扩展分组显示，内置功能标注「内置」。
- 内置功能可以随时开关，但不能删除——删除后没有重新安装的入口。

## 密码本

- 保存的账号可以记录作者名，登录成功后会自动读取当前作者名并绑定。
- 账号下拉按作者名显示，形如「笔名 · 账号」，多账号时更容易分辨。
- 新增「管理」面板，可多选批量删除，也可逐条手动标注或修改作者名。

## 书籍优先级

- 创作中心每本书封面右上角新增星标，点亮即设为优先级。
- 点亮的书排在创作中心「优先级作品」栏最前面，数据看板也会默认定位到这一本。
- 同时点亮多本时，最近点亮的那本优先；在数据看板手动选过查看范围后，不再被星标改回来。

## 弹窗遮挡修复

- 本版新增的「清除所有数据」「恢复数据」「是否继承旧数据」三个确认框，打开时会先收起内嵌的作者后台或喵语数据页面，关闭后原样挂回，保留当前页面与填了一半的表单。
- 与 v1.0.6 修复的更新窗口遮挡问题使用同一套处理。

## 获取与更新

已有用户可通过软件内的更新提示升级。新用户请下载本次 Release 的 `ciweimao-writer-tool-v1.0.7-windows-x64.zip` 完整免安装包，解压后启动。

`ciweimao-writer-tool-v1.0.7-app.zip` 为软件内置更新器使用的应用更新包，不是独立运行的完整程序。

从 1.0.6 升级会保留原有作品、草稿、敏感词库与密码本；升级前建议在「设置 → 数据管理」里点一次「立即备份一份」。
