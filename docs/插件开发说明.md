# 刺猬猫作家助手插件开发说明

## 快速开始

1. 打开软件的“插件中心”。
2. 点击“创建开发模板”。
3. 软件会在当前数据保存位置的 `plugins` 文件夹中生成一个示例插件。
4. 修改插件文件后，回到插件中心点击“重新加载”。

插件目录名必须与 `manifest.json` 中的 `id` 完全相同。

```text
my-writing-plugin/
├─ manifest.json
├─ page.html
├─ style.css
├─ main.js
└─ README.md
```

## manifest.json

```json
{
  "id": "my-writing-plugin",
  "name": "我的写作插件",
  "version": "1.0.0",
  "author": "作者名",
  "description": "插件用途说明",
  "permissions": ["editor.read"],
  "contributes": {
    "navigation": { "title": "我的插件页" },
    "editorStat": false,
    "floatingWidget": false
  }
}
```

`id` 只能使用小写英文字母、数字、横线和下划线。

可申请的权限：

- `editor.read`：读取当前打开作品、章节标题、正文、选中文字和字数。
- `editor.write`：修改或插入当前章节正文。插件写入不会计入码字统计。
- `stats.read`：读取本地已保存码字统计。
- `stats.author`：由用户操作触发，刷新并读取作者后台的作品统计数据。
- `ui.editorStat`：在创作编辑器的码字面板中显示插件指标。
- `ui.theme`：在插件前台页面应用或恢复本插件声明的全局主题。

插件自己的 `storage.get/set` 无需额外权限，数据按插件 ID 隔离保存。

## 页面文件

- `page.html`：插件页面的主体 HTML。不要在这里写 `<script>`，脚本应放在 `main.js`。
- `style.css`：插件页面样式。
- `main.js`：插件逻辑，可通过全局对象 `PluginAPI` 调用宿主能力。
- `background.js`：可选的后台逻辑；启用 `editorStat` 时可在这里定时更新编辑器指标。
- 悬浮球应直接写在插件自己的 `page.html` 中，由插件 iframe 自己绘制、拖动和保存位置。启用 `contributes.floatingWidget` 后，宿主会让这个 iframe 在其他页面继续驻留，不会额外复制一个宿主悬浮球。

插件页面运行在无同源权限的沙箱中，不能访问作家助手页面、Node.js、文件系统、网络、账号、Cookie 或密码本。

## PluginAPI

宿主请求方法返回 Promise；`on`、`floating.onChange`、`floating.bindDrag` 返回取消订阅/解绑函数，`floating.getState` 同步返回最近状态。

```js
// 应用和通知
await PluginAPI.app.info();
await PluginAPI.app.notify('处理完成');

// 插件独立存储
await PluginAPI.storage.set('setting', { enabled: true });
const setting = await PluginAPI.storage.get('setting');

// 需要 editor.read
const chapter = await PluginAPI.editor.getContext();
// 返回 bookId、bookName、chapterId、title、content、selectedText、words

// 需要 editor.write；写入后宿主会自动保存
await PluginAPI.editor.setContent('新的完整正文');
await PluginAPI.editor.insertText('插入内容', 'selection');
await PluginAPI.editor.insertText('添加到开头', 'start');
await PluginAPI.editor.insertText('添加到结尾', 'end');

// 需要 stats.read
const stats = await PluginAPI.stats.get();
// stats.days：键盘码字统计（不含粘贴）
// stats.savedDays：成功保存的正文净新增字数（包含粘贴，适合稿费等产出计算）
// stats.currentChapterSavedWords：当前章节最近一次成功保存后的正文总字数

// 需要 stats.author；会打开作者后台页面重新采集，耗时取决于作品数量
const authorStats = await PluginAPI.stats.refreshAuthorSubscriptions();
// authorStats.books：本地 bookId、后台 platformBookId、作品名与章节均订 avgSubs

// 需要 ui.editorStat，通常从 background.js 调用
await PluginAPI.ui.setEditorStat({
  label: '本章预计稿费',
  value: '¥123.45',
  detail: '本章已保存 2,000 字 · 今日预计 ¥400.00'
});
```

`contributes.navigation` 会在左侧导航新增插件页面入口；只有 `contributes.editorStat` 会启动 `background.js`。`contributes.floatingWidget` 会在应用启动后自动加载插件页面，并让 iframe 内的原生悬浮球在其他页面继续显示。

## 常驻插件接口（API 1.1.0）

参考 DSH 的声明式挂载、事件与资源清理思路，常驻插件使用独立 iframe。每个已启用的悬浮插件只创建一个实例，切换应用页面或打开其他普通插件页不会销毁它。停用、删除或点击“重新加载”会清理实例；重新加载后按需重建。悬浮层覆盖应用本地页面，作者后台等原生嵌入视图有独立层级，不属于本地页面 DOM 悬浮层。

接口设计参考：[DSH 插件入门和资源清理](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/develop/basic/index.md)、[DSH 服务与依赖](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/develop/framework/service.md)、[小鲸鱼的挂载代码](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/blob/main/lib/index.js)。这是当前软件自身的 iframe 接口，不兼容直接安装 DSH 插件包。

在清单中设置 `contributes.floatingWidget: true` 后，可在 `main.js` 中使用：

```js
await PluginAPI.ready; // 等待宿主握手，不靠固定延时猜测加载完成
const info = await PluginAPI.app.info();
// info.apiVersion、info.capabilities 可用来判断宿主能力

const ball = document.querySelector('#ball');
const panel = document.querySelector('#panel');
await PluginAPI.floating.configure({
  widget: { width: 72, height: 72 },
  panel: { width: 360, height: 280 }
});

function place(state) {
  // ballX / ballY 是球在 iframe 内的坐标；宿主负责保留应用内的位置。
  ball.style.left = `${state.ballX}px`;
  ball.style.top = `${state.ballY}px`;
  panel.hidden = !state.expanded;
  // state.edge: tl/tr/bl/br，用于选择面板在球的哪一侧展开。
  // state.width / height 是 iframe 实际大小。面板还应按该区域钳制坐标。
}
const stopState = PluginAPI.floating.onChange(place);
place(PluginAPI.floating.getState());
const stopDrag = PluginAPI.floating.bindDrag(ball, {
  onClick() {
    const state = PluginAPI.floating.getState();
    PluginAPI.floating.setExpanded(!state.expanded).catch(console.error);
  }
});

PluginAPI.on('open', () => {
  // 用户在插件中心点击“打开”：展示本插件设置，不创建第二个球。
});
PluginAPI.on('theme-changed', ({ theme }) => { /* 重新绘制自己的图表等 */ });
PluginAPI.on('view-changed', ({ view }) => { /* 应用当前本地页面名称 */ });
PluginAPI.on('storage-changed', ({ key }) => { /* 同 ID 的另一个实例更新了存储 */ });
PluginAPI.on('dispose', () => {
  stopState();
  stopDrag();
  // 自己创建的定时器、订阅等在此清理。
});
```

宿主保存各插件的位置到该插件存储的 `__host.floating.position`，插件不要覆盖此键。默认自由放置，松手不会强制吸附。拖动使用屏幕坐标并按帧合并移动消息，支持 pointercancel；展开和收起保持球的应用内坐标。组件尺寸以 CSS 像素计，输入限制为 32～1000，最终容器不会超出窗口。

SDK 管理通过 `bindDrag` 注册的监听器和待处理请求；卸载时会解绑、取消请求。普通插件已有的 `editor`、`stats`、`storage` 和 `ui.setEditorStat` 接口继续可用。健康助手 1.0.6 已接入正式接口。早期健康助手的 `ciweimao-plugin-host-event` 布局消息保留有限兼容，新的插件应使用上述接口，避免自行拼接消息。

## 导入与分发

把上述文件放在一个文件夹内，再压缩为 ZIP 即可分发。ZIP 可以直接包含这些文件，也可以在最外层多包一层插件目录。用户在“插件中心”点击“导入插件包”，选择 `.zip` 文件。

插件不支持在页面中联网，也不能加载远程脚本。这是有意设置的安全边界。需要外部服务的插件应由用户明确审查源码后，再通过未来扩展的受控接口实现。

## 更新插件

当前版本不会自动覆盖同 ID 插件。更新时先在插件中心删除旧插件，再导入新的 ZIP。插件独立存储默认保留。

## 全局主题扩展（API 1.2.0）

在 manifest.json 的 contributes.themes 中声明主题。一个插件最多提供 8 套。导入并启用后，用户可在功能中心卡片上应用，也可通过“设置 → 外观 → 扩展主题”选择。启用插件只注册主题，用户的选择才会改变界面。

```json
{
  "id": "my-theme-pack",
  "name": "我的主题包",
  "version": "1.0.0",
  "permissions": ["ui.theme"],
  "contributes": {
    "themes": [{
      "id": "forest-light",
      "name": "林间浅色",
      "base": "light",
      "variables": {
        "--bg": "#edf4ed",
        "--surface": "#fbfefb",
        "--text": "#203528",
        "--accent": "#87bc8a",
        "--radius": "14px"
      }
    }]
  }
}
```

主题 id 使用 2～64 位小写字母、数字、横线或下划线，以字母或数字开头。同一插件内不能重复。base 支持 light、pink、dark。未提供的变量沿用该基础主题。

颜色值支持 #RGB、#RGBA、#RRGGBB、#RRGGBBAA。--radius 使用 0px～24px。主题配方使用以下变量白名单，未知变量或含 URL、选择器、脚本等的值会在导入时被拒绝。

- 底色与边框包括 --bg、--surface、--surface-2～4、--border、--border-strong。
- 文字与强调色包括 --text、--text-2～3、--accent、--accent-hover、--accent-weak、--accent-ink、--accent-line。
- 状态色包括 --ok-bg、--ok-ink、--warn-bg、--warn-ink、--up、--down、--danger-bg、--danger-ink、--danger-line。
- 标签与选中区域包括 --chip-bg、--chip-ink、--hl-bg、--hl-ink、--track、--seg-active、--step-bg。
- 图表包括 --chart-line、--chart-grid、--chart-ink、--chart-dot、--props-c1～4。
- 滚动条包括 --scroll、--scroll-hover、--chevron。通用圆角为 --radius。

如需在插件自己的页面提供切换按钮，声明 ui.theme 权限后可调用以下接口。

```js
const info = await PluginAPI.app.info();
if (!info.capabilities.includes('themes')) throw new Error('宿主尚未接入主题扩展');
const available = await PluginAPI.theme.list(); // 仅本插件已注册的主题
const current = await PluginAPI.theme.get(); // mode、effective、darkTone、pluginTheme
await PluginAPI.theme.apply('forest-light');
await PluginAPI.theme.reset();
```

apply 只能选择本插件声明的主题，reset 只能撤销本插件当前应用的主题。这两种写操作由前台插件页面发起。现有 theme-changed 事件继续可用，插件页面会收到新的配色样式。

选择保存在当前数据目录的 ui-prefs.json。localStorage 中的经过验证的配方仅用于首帧显示。重启时以数据目录和已启用插件的清单为准，移除、停用或损坏的主题会恢复到用户原先的内置主题。选择内置主题也会撤下扩展配色。创作编辑器的显示偏好保持独立。

主题生效期间，宿主会锁住内置的明暗切换：侧栏深浅按钮、设置里的主题档位与深色配色、创作中心的深色按钮一律禁用，API 层的 Theme.set / toggle / setDarkTone 也直接返回而不生效。原因是这些入口会清空当前选择，表现为「点一下切换，主题就没了」。因此**一个主题包应当同时提供 light 与 dark 两套**（pink 亦可），由用户在扩展主题下拉里切换，而不是依赖内置明暗按钮。停用插件或改选内置主题后，锁定自动解除。面向用户的说明见随包的《美化包制作说明.md》。

停用扩展只让它的主题暂时失效，宿主会保留用户的选择（ui-prefs.json 里的 pluginTheme 不清空），重新启用后自动恢复；只有删除扩展、或新版本不再声明该主题 id 时才真正清除并回退内置主题。插件在停用状态下不会收到 theme.apply，重新启用后由宿主按记录自动应用，不需要额外调用。

主题变量应用于主界面、创作中心、插件页面和敏感词侧栏。作者后台与喵语数据遵循各站点自身样式。

按上述声明制作独立主题包，将 manifest.json 与插件页面等文件压成 ZIP 后，即可通过功能中心导入。

注册式主题、基础变量回落及停用清理参考了 DSH 主题机制与达妮娅皮肤的生命周期设计。示例配色及实现由本项目独立提供。[DSH 主题机制](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-theme/README.md) · [达妮娅主题](https://github.com/Ewnscat-ya/dsh-client-ui-skin-denia)

## 背景图片与组件换肤（API 1.3.0）

主题声明新增 background、styles、decorations、effects。图片放在插件包的 assets 目录，文件名限英文、数字、横线、下划线。支持 PNG、JPEG、WebP、GIF，单张不超过 8MB；ZIP 及解压后总量不超过 32MB，脚本和文本仍保持每个 512KB、合计 2MB 的限制。LICENSE 和 NOTICE 会随插件导入。

以下字段与 id、name、base、variables 放在同一套主题中：

```json
{
  "background": { "image": "assets/forest.webp", "opacity": 0.7, "blur": 0, "fit": "cover", "position": "center" },
  "styles": {
    "sidebar": { "background": "#fffbffb8", "backdropBlur": 12 },
    "panel": { "background": "#fffbffcc", "borderColor": "#d7c5e6", "borderRadius": 20,
      "shadow": { "x": 0, "y": 8, "blur": 28, "color": "#73549420" } },
    "primaryButton": { "borderRadius": 12,
      "gradient": { "from": "#bd91cb", "to": "#9cb6df", "angle": 125 } }
  },
  "decorations": [{ "id": "right-art", "image": "assets/character.webp", "anchor": "bottom-right",
    "width": 260, "height": 65, "offsetX": 8, "offsetY": 0, "opacity": 0.9, "layer": "background", "enabled": true }],
  "effects": { "bubbles": true, "bubbleCount": 14, "bubbleSpeed": 0.8, "trim": true, "stars": true }
}
```

background 的 opacity 范围为 0～1，blur 为 0～24px，fit 为 cover / contain，position 为 center / top / bottom / left / right。图片可为资源路径或 data:image 数据；不读取插件目录以外的文件，不加载远程资源或 SVG。图片格式与实际文件头会同时校验。

styles 可使用 sidebar、topbar、panel、button、primaryButton、navItem、navActive、input、writerWorkspace、writerPaper、writerDirectory、writerStats、toolbar、dialog、title 这些组件名。插件无需依赖主程序的内部选择器。支持以下视觉属性：

- background、color、borderColor：十六进制颜色，可包含透明通道。
- borderWidth：0～6，borderRadius：0～48，backdropBlur：0～24，单位为 px。
- borderStyle：solid / dashed / dotted / double。
- shadow：x（-24～24）、y（-24～48）、blur（0～80）、spread（-20～20）和 color。
- gradient：from、to 两种颜色及 angle（0～360）。
- fontWeight：400～800；paddingX：0～32、paddingY：0～24，单位为 px。

这些接口不会允许插件隐藏宿主控件或插入主界面脚本。现有字体字号偏好及章节内容不被改写。页面和浮层插件仍处于原有隔离环境。

decorations 最多 6 个，ID 不可重复。anchor 支持四个角，也支持 sidebar-bottom（在侧栏底部预留空间展示，不遮挡导航和底部按钮，此时不使用偏移）。width 为 32～640px，height 为最大高度 10～85vh，offsetX / offsetY 为距相应边缘的偏移（-200～400px），opacity 为 0～1。layer 为 background 或 foreground。立绘均不接收鼠标操作；窗口窄于 980px 时隐藏立绘。专注写作时隐藏浮动立绘和动态效果。泡泡数量为 4～30、速度为 0.3～2；系统要求减少动画时不播放泡泡动画。

### 插件调色板与个人设置

有 ui.theme 权限的前台插件页面可调用 configure，更新自己某一套主题的外观。对象字段合并保存，装饰数组整组替换；传 null 恢复该套主题的默认外观。设置其他主题不会自动切换当前主题。

```js
await PluginAPI.ready;
const info = await PluginAPI.app.info();
if (!info.capabilities.includes('themeStyles')) throw new Error('宿主不支持图片换肤');
await PluginAPI.theme.configure('forest-light', {
  background: { image: uploadedDataURL, opacity: 0.8, blur: 2 },
  styles: { panel: { background: '#ffffffb8', backdropBlur: 12 } },
  effects: { bubbles: false }
});
await PluginAPI.theme.apply('forest-light');
await PluginAPI.theme.configure('forest-light', null); // 恢复此套主题的默认配置
```

上传可在插件页面通过普通 file input 与 FileReader 完成。图片及个人外观设置保存在当前数据目录的 plugin-theme-settings 下，明暗主题按不同主题 ID 分开存储，随数据目录备份。设置不会写回插件包。删除后重新安装同 ID 插件仍可保留个人外观；恢复默认可将其清除。大图不写入首帧 localStorage 缓存。插件停用、删除或切换为内置主题时，背景、立绘、效果与样式节点一并撤下。

### 侧栏图标

主题可通过 branding.icon 替换主界面左上角的侧栏图标。图片格式与大小限制和背景图片相同，显示在 34×34 的区域并保持比例。设置保存、明暗主题隔离及停用清理继续使用现有接口。

```json
{ "branding": { "icon": "assets/chibi-light.gif" } }
```

```js
const info = await PluginAPI.app.info();
if (!info.capabilities.includes('themeBranding')) throw new Error('请更新宿主以支持侧栏图标');
await PluginAPI.theme.configure('forest-light', { branding: { icon: uploadedDataURL } });
await PluginAPI.theme.configure('forest-light', { branding: { icon: null } }); // 此形态使用软件默认图标
```

图片成功加载后才替换原图标，加载失败保留原图。切换到没有自定义图标的主题、停用或删除插件时会恢复软件内置图标。这一设置的作用范围是软件侧栏，桌面快捷方式及任务栏图标由应用本身提供。
