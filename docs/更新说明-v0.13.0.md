# v0.13.0 更新说明

更新日期：2026-11-05

- 软件内部版本号和界面版本号统一为 0.13.0。
- 评论审查列表新增“查看原段”：点击后从作者后台只读获取对应章节，并在间贴下方展开相应段落，再次点击收起。
- 同一段落在本次运行期间缓存，减少重复请求。

- 段落内容来自后台当前正文；若发布间贴后章节发生删改或重新排版，原段落编号可能不再对应原文。

本次提交不更新插件目录或插件压缩包。现有创作中心、码字统计、投稿功能与工程配置保留。

验证：修改脚本通过语法检查；段落序号及空行分隔解析通过基础校验。尚未使用登录后的真实间贴验证平台段落编号。
