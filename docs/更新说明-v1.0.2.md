# 刺猬猫作家助手 v1.0.2 更新说明

## 稿费统计同步后台均订

- 稿费统计页点击“刷新”时，会重新读取作者后台的章节均订。
- 后台均订会自动写入对应作品的平均订阅数，并立即更新当日、7 日、30 日及本章预计稿费。
- 多本作品优先按照作者后台作品号对应，旧作品仅在书名唯一且完全相同时回退匹配。
- 作者后台没有均订数据时保留用户手动填写的平均订阅数，不会被刷新清空。
- 刷新过程会显示读取状态，登录失效、作品同步中等情况会给出明确提示。

## 稿费计算器插件 1.2.0

- 内置稿费计算器升级至 `1.2.0`，随新版软件自动安装或更新。
- Release 同时提供 `income-calculator-v1.2.0.zip`，可在插件中心单独导入。
- 新增受控的作者后台统计权限，第三方插件必须显式声明后才能调用。
- 详细操作见《稿费统计后台均订同步操作说明》。
