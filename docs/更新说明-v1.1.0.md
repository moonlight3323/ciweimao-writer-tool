# 刺猬猫作家助手 v1.1.0 更新说明

这一版带来「摸鱼码字」：在任意窗口之上开一个几乎看不见的透明浮层，随手写，正文实时同步到本章。顺带把码字台的字体从 4 种扩到 11 种。

## 摸鱼码字

- 功能中心新增「摸鱼码字」开关，开启后码字台工具栏出现「摸鱼码字」按钮；点它主窗口收起，屏幕上只剩一个透明输入框。
- 浮层里的正文会实时同步进当前章节，自动保存、字数统计、错别字提示都按原样继续走，不用来回切换窗口。
- 第一次点按钮会先弹一张说明卡，把隐藏、呼出、拖动三件事讲清楚，看过一次就不再出现。
- 浮层可以整体透明：文字颜色跟正文一致，也能设描边，压在白色网页或深色编辑器上都不糊。
- 顶部那一条只有左侧握把带一点粉色，按住它就能拖动浮层，鼠标是十字箭头；位置和大小会记住，下次打开还在原处。
- 隐藏与呼出的快捷键可以自己按出来，存进设置后即时生效；万一这个组合被别的软件占用了，面板会明确告诉你实际用的是哪一个备用键。
- 除了快捷键，在浮层上同时按鼠标左键和右键也能立刻收起来。
- 浮层右侧面板可调字号、行高、字色、底色深浅和宽度；正文字体跟随码字台当前的字体设置。

## 码字台

- 显示设置的字体从 4 种扩到 11 种，按黑体、宋体、楷体分组：新增黑体、思源黑体、等线、仿宋、华文楷体、霞鹜文楷、幼圆。
- 思源、霞鹜这类字体需要系统里装了才生效，没装会自动退回最接近的一种，不会变成方块。
- 配置里存着已经不存在的老字体名时，会自动回到微软雅黑，不会让字体下拉框空着。

## 修复

- 修好优先级作品排序偶发失效的问题：一处脚本因变量重名整份没被执行，星标排序会悄悄退回默认顺序。

## 获取与更新

已有用户可通过软件内的更新提示升级。新用户请下载本次 Release 的完整免安装包 `ciweimao-writer-tool-v1.1.0-windows-x64.zip`，解压后启动。

`ciweimao-writer-tool-v1.1.0-app.zip` 为软件内置更新器使用的应用更新包，不是独立运行的完整程序。

从 1.0.9 或更早版本升级都会保留原有作品、草稿、敏感词库与密码本；升级前建议在「设置 → 数据管理」里点一次「立即备份一份」。
