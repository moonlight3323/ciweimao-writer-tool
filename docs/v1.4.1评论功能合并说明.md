# v1.4.1 评论管理功能合并说明

本分支以 GitHub `main` 的 v0.13.2 为基线，将「刺猬猫作者助手 v1.4.1」中与现有评论审查架构兼容的能力合并进来。

## 已合并

- 抓取与同步可同时选择「间贴（段评）」和「普通书评」。
- 评论审查页可按作品、评论类型、风险等级和关键词筛选。
- 设置页可调整高/中风险阈值，并维护自定义风险词与读者保护名单。
- 读者历史会按读者 ID 跨作品累计，最多保留 50 条文本样本和 200 个去重标识。
- 可把读者加入本地关注名单，并从作者后台的读者管理页查询粉丝值。
- 公开榜单从点击/收藏两类扩展为点击、收藏、推荐、订阅、月票、吐槽、新书、刀片、更新九类。

## 安全边界

- 普通书评本次只做抓取、审查和筛选，不复用间贴的删除接口。
- 原 v1.4.1 说明中已标注「实际未成功」的回复功能未合并。
- 置顶、透明贴、隐藏等能力会在页面解析时识别，但未经登录态实测前不开放自动执行。
- 本地关注名单只是作者的记录，不会自动删除、禁言或修改平台状态。

## 本分支未合并

- v1.4.1 的可选网络 AI 审查会把评论发往第三方，与当前项目「本机只读 AI 接口」的隐私边界不同，未直接搬入。
- 手工 Cookie 登录会扩大凭据暴露面；当前项目已有内嵌登录与 Windows DPAPI 密码本，未再增加 Cookie 粘贴入口。
- v1.4.1 的收益中心与当前数据看板/稿费插件职责重叠，为避免改动用户现有的稿费统计口径，本分支不替换原模块。

## 本地数据

新增数据仍保存在用户选择的数据目录，不会强制写入 C 盘：

- `review-settings.json`：审查阈值、自定义词、保护名单。
- `reader-history.json`：跨作品读者历史。
- `reader-watchlist.json`：本地关注名单。
