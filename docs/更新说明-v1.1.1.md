# 刺猬猫作家助手 v1.1.1 更新说明

本次 v1.1.1 修订版新增主题插件接口，并补齐密码本工具条、账号填入和弹窗遮挡修复，同时保留原有备份恢复、导入导出与更新器修复。

## 主题插件接口

- 插件 API 升级到 1.3.0，可声明全局配色、背景图片、组件样式、立绘装饰及左上角侧栏图标。
- 支持在插件页面选择本地图片，分别保存各套主题的背景与外观；重启保留选择，停用或删除插件后恢复内置主题。
- 主题覆盖主界面、创作中心及本地辅助页面，专注写作时隐藏浮动立绘与动态效果；支持新接口的主题需单独导入。
- 本次发布仅包含宿主接口与开发说明，不包含本机测试用的竹影、达妮娅两个主题包。

## 密码本

- 打开或重新挂回作者后台后主动同步浏览器状态，登录页的密码本工具条无需刷新即可显示。
- 账号与邮箱模式填入时同步切换全部账号、密码分组，避免调用站点页签脚本造成“填入中”卡住。
- 标注作者名等输入弹窗显示前暂时摘下内嵌网页，关闭后恢复同一页面，网页不会挡住输入框。

## 数据恢复与备份

- 修好「恢复数据」：以前从单文件备份恢复必然失败，清除后再恢复还会把配置建成同名目录、重启后连窗口都没有；现在按文件写回，v1.1.0 的旧备份也能直接用。
- 恢复现在是真覆盖：备份里没有的旧文件会先清空，不再新旧内容混在一起；只要有一个文件没复制成功就中止清除，原数据不会被删。

## 导入与导出

- 多页章节导出的 TXT 顺序不再错乱：以前会拼成 71..120、21..70、1..20，现在收集完所有页后按章节号整体排序。
- 导入 TXT 自动识别编码，UTF-8（含 BOM）、UTF-16LE/BE、GBK 都能认，GBK 文件不再整本乱码。

## 字数与发布校验

- 归档字数与作品库字数统一为「去掉空白后计数」，两处数字不再对不上。
- 删间贴、禁言前的「必须在作者后台」校验真正生效了：之前那行正则被写坏，校验等于没执行。

## 稳定性与更新

- 删除间贴、禁言、密码本读取与填入都补了超时，页面跳转时不再永久转圈；写日志失败也不会把已成功的操作回报成失败。
- 修好完整包跨重启后丢失类型的问题，不会再错把完整包当成 app 包覆盖进 resources\app。
- 更新回滚会校验目录是否真的恢复成功，move 失败时用 robocopy 兜底，不会从砍了一半的目录启动。
- 关闭窗口前会把最后不到 900ms 的输入写盘，不再丢字；自动保存改为逐章浅拷贝，大文件也不会卡。
- 单本上限从 20MB 放宽到 60MB；作品库超过 200 本时，被挤出索引的书目目录会一起清掉，不留孤儿数据。
- 章节切换、返回作品库、一键排版、查找替换遇到保存失败会明确提示并中止，不再出现「点了没反应」。

## 界面与浮层

- 修好深色模式下番茄钟等常驻浮层周围出现白色底的问题；切换深浅色时侧栏与浮层不再闪一下旧颜色。
- 摸鱼浮层关闭时最后一段输入不再丢失，坐标为空时不会再钉到屏幕左上角；插件导入残留的临时目录不再显示成坏插件。

## 获取与更新

已有用户可通过软件内的更新提示升级。新用户请下载本次 Release 的完整免安装包 `ciweimao-writer-tool-v1.1.1-windows-x64.zip`，解压后启动。

本次沿用 v1.1.1 标签重新发布；已安装旧版 v1.1.1 的用户需手动下载修订后的完整包，同版本不会触发版本号升级提示。

`ciweimao-writer-tool-v1.1.1-app.zip` 为软件内置更新器使用的应用更新包，不是独立运行的完整程序。

从 1.1.0 或更早版本升级都会保留原有作品、草稿、敏感词库与密码本；升级前建议在「设置 → 数据管理」里点一次「立即备份一份」。
