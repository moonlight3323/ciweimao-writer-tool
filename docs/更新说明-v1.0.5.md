# 刺猬猫作家助手 v1.0.5 更新说明

## 更新器修复重发

- 修复更新包下载完成后，重启时过早判断启动失败、自动回滚的问题。
- 调整启动等待时间，改善启动较慢的电脑上的更新体验。
- 旧程序没有退出时停止替换，避免程序仍在运行时覆盖文件。
- 更新失败时区分文件复制失败、启动确认超时等原因，方便排查。
- 修正更新过程中提前清理脚本和备份的问题。

本次为同版本修复重发，版本号仍为 1.0.5。已经安装 1.0.5 的用户不会看到更高版本提示，建议重新下载下方 `windows-x64.zip` 完整便携包，退出旧程序后解压到新文件夹启动。此前从 1.0.3 或 1.0.4 自动升级失败的用户，也请使用完整包手动升级一次。保留原数据保存目录，不要删除作品数据。

## 内置健康小助手

- 新增内置健康小助手，提供番茄钟、喝水提醒和睡觉提醒。
- 悬浮球可在应用本地页面持续显示，切换页面或打开其他插件时继续计时。
- 支持自由拖动，在当前位置松手即可放置；点击球体展开计时面板。
- 弹窗根据位置选择展开方向，展开和收起时保持球的位置。
- 在插件中心点击“打开”可调整健康助手设置，也可以通过开关停用。

## 插件接口优化

- 新增常驻悬浮组件接口，多个悬浮插件可以独立运行。
- 统一拖动、弹窗尺寸和位置管理，改善拖动跟手性及边角显示。
- 新增插件就绪、页面切换、主题变化和卸载通知。
- 切换主题时保留插件界面状态，停用或移除时自动清理实例。
- 更新插件开发说明，方便开发者接入自己的悬浮组件。

健康小助手版本为 1.0.6，插件接口版本为 1.1.0。悬浮层覆盖应用本地页面；作者后台等原生嵌入网页暂不支持覆盖。
