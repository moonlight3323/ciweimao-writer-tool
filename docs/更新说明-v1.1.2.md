# 刺猬猫作家助手 v1.1.2 更新说明

本版扩展主题插件接口，补齐密码本工具条、账号填入和输入弹窗的三处修复。保留 v1.1.1 已有的数据恢复、导入导出、自动保存与更新器修复。

## 主题插件接口

- 插件 API 升级到 1.3.0，可声明全局配色、背景图片、组件样式、立绘装饰及左上角侧栏图标。
- 支持从插件页面选择本地图片，各套主题的背景与外观分别保存；重启保留选择，停用或删除插件后恢复内置主题。
- 主题覆盖主界面、创作中心及本地辅助页面；专注写作时隐藏浮动立绘与动态效果，装饰不阻挡正文输入和按钮操作。
- 补充图片类型与路径校验、主题权限和前台操作限制，以及开发说明与回归测试。
- 本次发布不包含本机测试用的竹影、达妮娅主题包；主题需通过功能中心单独导入。

## 密码本

- 打开或重新挂回作者后台后主动同步浏览器状态，登录页的密码本工具条无需刷新即可显示。
- 账号与邮箱模式填入时同步切换全部账号、密码分组，避免调用站点页签脚本造成“填入中”卡住。
- 标注作者名等输入弹窗显示前暂时摘下内嵌网页，关闭后恢复同一页面，网页不会挡住输入框。
- 连续或嵌套输入弹窗保留外层遮罩状态，避免原生网页提前恢复到弹窗上方。

## 获取与更新

已有用户可在软件内检查更新，v1.1.1 用户也会按新版本号收到升级提示。新用户请下载完整免安装包 `ciweimao-writer-tool-v1.1.2-windows-x64.zip`，解压后启动。

`ciweimao-writer-tool-v1.1.2-app.zip` 为内置更新器使用的应用更新包，不是独立运行程序。升级保留原有作品、草稿、统计、密码本和插件设置。
