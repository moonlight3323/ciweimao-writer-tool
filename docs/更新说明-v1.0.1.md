# 刺猬猫作家助手 v1.0.1 更新说明

## 主动检查更新

- 设置页新增“软件更新”区域，可以随时点击“立即检查更新”。
- 检查完成后会明确显示当前已是最新版、发现新版本或连接失败，不再只能等待下次启动。
- 主动检查时即使此前跳过了该版本，也可以重新查看更新内容并安装。
- 设置页增加“查看发布页”入口，便于手动下载安装包。

## 修复更新清单缓存

- 更新清单优先通过 GitHub Contents API 获取 main 分支的实时内容。
- 请求加入 `no-cache` / `Pragma: no-cache` 头和唯一查询参数，避免 `raw.githubusercontent.com` 的旧缓存导致漏报新版本。
- 保留原始 Raw 地址作为备用来源，主地址不可用时仍可继续检查。
- 自动下载、SHA-256 校验、失败回滚及更新数据安全规则保持不变。

## 验证

- 语法与项目配置检查通过。
- 97 项自动测试全部通过。
- 已使用与客户端相同的更新模块联网读取清单，能够正确识别 GitHub 当前版本。
