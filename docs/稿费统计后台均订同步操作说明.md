# 稿费统计后台均订同步操作说明

适用于刺猬猫作家助手 `1.0.2` 及以上版本，以及稿费计算器插件 `1.2.0`。

## 功能说明

稿费计算器可以重新读取作者后台的章节均订，并自动填入对应作品的“平均订阅数”。填入后，当日、7 日、30 日稿费以及创作中心右侧的“本章预计稿费”都会立即重新计算。

作者后台没有返回章节均订时，插件不会清空原来的数值，会继续保留用户手动填写的平均订阅数。

## 使用前准备

1. 在作家助手中登录刺猬猫作者后台。
2. 确认需要统计的作品已经进入创作中心作品库。
3. 建议先同步或绑定作者后台作品号。未绑定作品号时，插件只会在书名唯一且完全相同的情况下自动对应。

## 刷新章节均订

1. 打开左侧“稿费统计”。
2. 点击页面右上角“刷新”。
3. 等待页面完成作者后台数据读取。读取时后台页面会自动切换作品，这是正常现象。
4. 页面出现“已更新 X 本作品”后，在“插件设置”里选择作品。
5. 检查“该作品平均订阅数”，它应当已经更新为作者后台的章节均订。

刷新会读取全部后台作品，因此作品较多时需要等待更长时间。每次点击“刷新”都会重新读取一次，不使用上一次缓存的均订。

## 多本作品

插件会按作品分别保存平均订阅数。刷新完成后，在“作品”下拉框中切换不同书籍，即可查看各自的均订。

作品对应顺序如下：

1. 优先使用已经绑定的作者后台作品号。
2. 作者库作品可以使用相同作品号直接对应。
3. 旧作品没有绑定作品号时，仅使用唯一且完全相同的书名作为备用匹配。
4. 存在两本同名作品时不会自动匹配，需要先在创作中心完成作品绑定。

## 手动填写

如果后台作品还没有章节均订，可以直接修改“该作品平均订阅数”。输入后会自动保存并实时更新稿费预估。

以后点击刷新时，只要作者后台仍然没有均订，手动填写的数值就不会被覆盖；后台出现有效均订后，插件会改用后台最新数据。

## 独立插件包

Release 中的 `income-calculator-v1.2.0.zip` 可以在“插件中心”通过“导入插件包”安装。

如果已经存在旧版稿费计算器，需要先在插件中心删除旧插件，再导入新 ZIP。插件设置数据会保留。

稿费计算器 `1.2.0` 需要作家助手 `1.0.2` 或更高版本提供后台统计接口，旧版软件需要先升级再导入插件。

## 常见提示

- “登录态已失效”：重新登录作者后台后再次刷新。
- “正在同步作品”：等待当前作品同步完成后再次刷新。
- “本作品暂无均订”：后台没有返回章节均订，当前手填值保持不变。
- “未与本地作品对应”：先在创作中心同步或绑定对应的作者后台作品。

页面金额均为估算结果，稿费以实际发放为准。
