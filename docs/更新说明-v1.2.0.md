# 刺猬猫作家助手 v1.2.0 更新说明

这一版修的是「界面突然变暗、什么都点不了」：开着作者后台时点关闭窗口，询问卡片会被后台页面整个盖住，两个按钮都在页面底下，看起来就像卡死了。现在所有弹窗都不会再被内嵌页面压住。

## 弹窗与页面层级

- 修复开着作者后台（或喵语数据）时点窗口关闭，询问卡片被后台页面盖住、按钮点不到的问题。这是唯一漏掉的场景，只在「页面开着 + 点关闭」同时成立时出现，所以表现为偶发。
- 新增统一保护：任何弹窗出现时都会先把内嵌页面收起来，关掉弹窗再按各自流程决定是否挂回。以后新增的弹窗不需要各自记得处理，不会再出现「网页浮在最前、其余部分变暗模糊、点什么都没反应」。
- 选择「最小化到托盘」时，刚才收起的后台页面会原样回到原来的位置与状态（不重新加载，填了一半的章节表单还在）；选择「直接退出」则不再挂回。
- 弹窗全部关闭后，界面滚动锁定会一并解除，不会因为某个弹窗收尾异常留下「能看见但滚不动」的残留状态。

## 获取与更新

已有用户可在软件内检查更新，v1.1.7 用户也会按新版本号收到升级提示。新用户请下载完整免安装包 `ciweimao-writer-tool-v1.2.0-windows-x64.zip`，解压后启动。

`ciweimao-writer-tool-v1.2.0-app.zip` 为内置更新器使用的应用更新包，不是独立运行程序。升级保留原有作品、草稿、统计、密码本和插件设置。
