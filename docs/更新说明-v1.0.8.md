# 刺猬猫作家助手 v1.0.8 更新说明

这一版主要修两件事：**更新下载在国内网络下装不上**，以及**密码本「记住这次输入」点了像没反应**。

## 更新下载更可靠

- 更新包改由 CDN 分发，不再依赖本机能否连上 GitHub。此前所有「GitHub 加速镜像」都是实时回源 GitHub，国内访问不通时会一起失败，表现就是进度条一直停在 0 KB。
- 下载地址现在会自动补充备用线路：一个地址不通会立刻换下一个，不用你手动重试。
- 单个地址的等待时间从 2 分钟缩短到 25 秒，网络不通时不会再让人干等。
- 下载失败时会说明具体原因（请求超时 / HTTP 404 / 下载不完整），不再只有一句「没能下到更新包」。
- 网络类失败多一个「手动下载」按钮，直接打开 Release 页面。
- 点「重试」会重新读取更新清单，服务端换了下载地址后点一下就能好，不必重启软件。

## 密码本：记住这次输入

- 保存成功或失败会直接显示在按钮上（「已保存 ✓」/「没保存」），1.8 秒后恢复原样，不用再去看工具条最右端那一行小字。
- 修掉提示被内嵌网页盖住的问题：登录页打开时工具条会展开一行提示，此前这一段没有重新计算网页的位置，提示正好压在网页下面，看起来就像点了没反应。
- 纠正用法说明：原来是「登录成功后点记住这次输入」，但登录成功那一刻工具条就收起了，照着做点不到。正确做法是填好账号密码后、点登录之前保存。
- 保存失败时如实显示原因（例如「登录框里还没有内容」），不再只留在隐藏的提示里。

## 获取与更新

已有用户可通过软件内的更新提示升级。新用户请下载本次 Release 的 `ciweimao-writer-tool-v1.0.8-windows-x64.zip` 完整免安装包，解压后启动。

`ciweimao-writer-tool-v1.0.8-app.zip` 为软件内置更新器使用的应用更新包，不是独立运行的完整程序。

从 1.0.7、1.0.6 或更早版本升级都会保留原有作品、草稿、敏感词库与密码本；升级前建议在「设置 → 数据管理」里点一次「立即备份一份」。
