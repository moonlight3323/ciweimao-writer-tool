# 刺猬猫作家助手 v1.0.9 更新说明

这一版修发布链路的两处硬伤（点了没反馈、加星后星标消失），并按你的要求把安装包里的文档精简了一遍。

## 发布章节

- 修好「点发布章节后界面没反应」：站点返回的结果现在会同时显示在网页里和窗口顶栏，不用再靠猜它到底发没发出去。
- 发布成功后如果站点没给跳转地址，程序会把页面带到章节管理页，能当场看到这一章确实发出来了。
- 页面响应加了超时：正常两秒内出结果；后台掉线或页面卡住时会明确说超时，不会一直停在「正在提交校验」。
- 发布只保留网页上「发布章节」这一个入口：敏感词侧栏不再代发，也去掉了「直接提交」，避免绕开站点的确认框、造成同一章重复提交。

## 创作中心

- 修好没读到封面的书加星后卡片塌成一条、星标消失点不到、也没法取消优先级的问题。星标现在挂在卡片上，封面怎么坏都点得到。
- 封面图加载失败会自动退回渐变占位，不再留一条破图空条。
- 引导文案统一成「封面右上角」（原来一处写左上角、一处写右下角，照着找找不到）。

## 安装包

- 便携包不再附带历次更新说明与开发笔记，只保留使用说明、功能说明、安全说明与插件开发说明。

## 获取与更新

已有用户可通过软件内的更新提示升级。新用户请下载本次 Release 的 `ciweimao-writer-tool-v1.0.9-windows-x64.zip` 完整免安装包，解压后启动。

`ciweimao-writer-tool-v1.0.9-app.zip` 为软件内置更新器使用的应用更新包，不是独立运行的完整程序。

从 1.0.8 或更早版本升级都会保留原有作品、草稿、敏感词库与密码本；升级前建议在「设置 → 数据管理」里点一次「立即备份一份」。
