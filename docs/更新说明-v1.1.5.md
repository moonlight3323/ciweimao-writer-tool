# 刺猬猫作家助手 v1.1.5 更新说明

这一版只修一件事：敏感词侧栏有时「点了不出来」。不是功能坏了，是窗口开出来了但你**看不见**——所以这一版把它彻底摆到你眼前，出问题也会直说原因。

## 敏感词侧栏

- 侧栏窗口改为始终浮在应用窗口之上。以前窗口贴在主窗口右缘时会和主窗口重叠十几个像素，被压在下面，看起来就是「点了按钮没反应」，再点一次反而把它收掉。
- 打开侧栏时会核实窗口是否真的显示出来了。以前只要调用没报错就当成功，即使窗口因页面尚未加载完而停在隐藏状态也一样；现在显示不出来会直接在顶栏写「侧栏窗口没能显示，点顶栏「敏感词侧栏」再试一次」，不会让你对着空白等。
- 侧栏开在另一块屏幕上时会自动移回主窗口旁边。多显示器、或者你以前拖过侧栏窗口，它可能一直待在副屏；以前主屏上看不到任何变化，再点顶栏按钮还会把它当成「已打开」收起来。现在顶栏会提示「侧栏在另一块屏幕上，已移回主窗口旁边」。
- 侧栏页面本身没能加载起来（文件缺失、被杀毒软件拦住）时，顶栏会直接写出失败原因，不再是全白窗口。
- 侧栏打不开时不再静默失败，顶栏那条状态栏是唯一不会被后台页面盖住的地方，现在所有失败都会说到这里。

## 获取与更新

已有用户可在软件内检查更新，v1.1.4 用户也会按新版本号收到升级提示。新用户请下载完整免安装包 `ciweimao-writer-tool-v1.1.5-windows-x64.zip`，解压后启动。

`ciweimao-writer-tool-v1.1.5-app.zip` 为内置更新器使用的应用更新包，不是独立运行程序。升级保留原有作品、草稿、统计、密码本和插件设置。
