# 刺猬猫作家助手 v0.14.0 更新说明

## 评论与间贴

- 合并普通评论与间贴抓取，并可按类型筛选。
- 新增评论阈值、自定义词、保护读者、跨作品读者历史、关注名单和粉丝信息查询。
- 间贴详情可直接查看对应段落文字。

## 平台榜单

- 从点击榜、收藏榜扩展为点击、收藏、推荐、订阅、月票、吐槽、新书、刀片、更新九类榜单。
- 保留周榜、月榜及名次变化对比。

## 内置稿费计算器

- 稿费计算器改为内置插件，随软件自动安装和更新，无需导入 ZIP。
- 支持按作品设置平均订阅数，统计今日、7 日、30 日预估稿费与全勤奖励。
- 复制粘贴正文在保存后可计入稿费估算，但不计入码字统计和码字速度。
- 结算日以每日 06:00 为界；删除作品后不再计入该作品的稿费数据。
- 页面显示金额均为预估，稿费以实际发放为准。

## 构建与授权

- 版本号更新为 0.14.0。
- 项目采用 AGPL-3.0，并在完整免安装包及应用代码包中附带授权文件和授权标识。
- 移除仓库与成品中的独立稿费插件 ZIP，CI 会验证内置插件和授权文件完整性。
